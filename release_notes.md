### What's Changed in v3.5.1

- **Fixed Native Desktop Window Crash (Fixes #13)**: Automatically unblocks bundled binaries on Windows at startup to prevent `Python.Runtime.Loader.Initialize` errors when extracting release archives via Windows Explorer.
- **Open Folder Shortcuts**: Added an "open" button next to the download directory selector, an "open folder" button in the progress panel upon completion, and a show-in-folder button for completed items in History.

**Full Changelog**: https://github.com/Vure-sh/crunchyroller/compare/v3.5.0...v3.5.1
